# 🎮 Tic Tac Toe Game in C++

## 📌 Overview

This project is a console-based Tic Tac Toe game developed using C++.  
It is designed to demonstrate core programming concepts including arrays, loops, functions, and conditional logic through an interactive game.

The game supports two-player gameplay with dynamic board updates, win/draw detection, input validation, and replay functionality.

---

## 🚀 Features

- Interactive two-player gameplay
- Dynamic game board display
- Input validation for valid moves
- Win detection logic
- Draw detection system
- Replay option after game completion
- Clean and modular code structure

---

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming Concepts
- Console-Based User Interface

▶️ How to Run
Using VS Code
Install MinGW Compiler
Install C/C++ Extension in VS Code
Open the project folder
Compile the program:
g++ main.cpp -o game
Run the executable:
./game

🎯 Game Rules
The game is played between two players: X and O
Players take turns selecting positions from 1 to 9
The first player to align three symbols horizontally, vertically, or diagonally wins
If all positions are filled without a winner, the game ends in a draw
